# DECISIONS Backend

AI-powered decision-making platform for e-commerce businesses. This is the backend API that powers the DECISIONS dashboard.

## Quick Start

### Prerequisites
- Node.js 18+
- PostgreSQL 13+
- Anthropic API key (Claude)
- Stripe API keys

### Setup

1. **Install dependencies**
   ```bash
   cd decisions-backend
   npm install
   ```

2. **Configure environment**
   ```bash
   cp .env.example .env
   ```
   Then update `.env` with:
   - `DATABASE_URL` — PostgreSQL connection string
   - `ANTHROPIC_API_KEY` — Claude API key
   - `STRIPE_SECRET_KEY` — Stripe test key
   - `JWT_SECRET` — Random secret for JWT signing

3. **Initialize database**
   ```bash
   npm run migrate
   ```

4. **Start development server**
   ```bash
   npm run dev
   ```

Server runs on `http://localhost:3000`

## API Endpoints

### Authentication
- `POST /api/auth/register` — Create account
- `POST /api/auth/login` — Login

### Pricing Recommendations
- `POST /api/decisions/pricing` — Get AI pricing recommendation

### Integrations
- `POST /api/integrations/shopify/connect` — Connect Shopify store
- `POST /api/integrations/n8n/connect` — Connect n8n webhook
- `POST /api/integrations/plausible/connect` — Connect Plausible analytics

### Analytics
- `GET /api/analytics/dashboard` — Get dashboard metrics
- `POST /api/analytics/track` — Track revenue from recommendations

## Database Schema

**Users** — User accounts with subscription tier
**Products** — Catalog of products being optimized
**Recommendations** — Pricing recommendations generated by Claude
**Revenue Tracking** — Actual revenue data after recommendations
**Integrations** — Connected third-party services
**Usage Tracking** — Freemium tier usage limits

## Pricing Logic

**Free Tier**: 1 pricing recommendation per month
**Pricing Optimizer ($99/mo)**: Unlimited recommendations + revenue tracking
**Premium ($299/mo)**: + Inventory optimization + hiring assistant + strategy calls
