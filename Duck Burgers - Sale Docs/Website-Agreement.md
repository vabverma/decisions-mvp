**Between:** Auto-Mate LLC ("Developer")
**And:** Ducks Burger Bar, [OWNER NAME] ("Client")
**Date:** _______________

## 1. Project Description
Developer has designed and built a custom website for Client ("the Site"), including:
- Home, Menu, About, Find Us, and Unlimited (promo/membership) pages
- Custom responsive design and animations
- Click-to-call and click-to-email contact links
- Real menu, photo, and video content supplied by or approved by Client

## 2. Deliverables
- [ ] Fully functional website as demoed at [live URL / staging URL]

- [ ] ___ rounds of revisions before final sign-off (recommend: 2)

**Not included** (call out explicitly to avoid scope disputes):
- Online ordering / payment processing (site links to Client's existing ordering provider)
- A submittable contact form with email delivery (site currently uses click-to-call/click-to-email links only — available as a scoped add-on)
- Ongoing content updates beyond initial launch, unless covered under Maintenance (Section 5)
- Copywriting/translation beyond what Client supplies
